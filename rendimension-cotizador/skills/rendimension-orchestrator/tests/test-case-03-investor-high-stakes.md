# Test Case 3 — Investor Deck (High Stakes)

## Input Prompt

"Rendimension Visualization Package: 8 photorealistic renders, 1 virtual tour, 1 floor plan. Total: $18,500. Timeline: 3 weeks. Includes 2 rounds of revisions."

## Expected Behavior

- Detect this is HIGH-IMPACT scenario (investors / pre-sales)
- Flag:
  - no narrative
  - no positioning
  - no business impact
- Rewrite as strategic communication slide

## Pass Criteria

- Positions as investor confidence tool
- Connects visuals to pre-sales / approval
- Sounds like part of a serious development strategy
- Does not read like a menu or checklist
- Makes $18,500 feel like a strategic investment, not an expense
