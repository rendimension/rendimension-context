# Test Case 2 — Real Client Pressure (Pricing Trap)

## Input Prompt

"Hi David, great meeting you yesterday. As discussed, I'm sending over pricing for your project. We can deliver 5 exterior renders and 3 interiors for $6,200. Let me know if you'd like to proceed."

## Expected Behavior

- Detect that this is NOT wrong structurally, but wrong strategically
- Identify missing:
  - client objective
  - business context
  - reason behind scope
- Rewrite WITHOUT losing clarity or making it fluffy

## Pass Criteria

- Keeps it as an email (not turns it into a speech)
- Introduces value framing
- Justifies scope based on objective
- Removes price-per-deliverable logic dominance
- Sounds like a partner following up, not a vendor quoting
- Maintains commercial usefulness — the client can still say yes
