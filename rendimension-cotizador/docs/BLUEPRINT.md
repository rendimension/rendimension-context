### SCREEN 1: HERO (Screenshot 3)

**What Stitch did right:**
- Dark navy background with gradient — premium feel, good
- Large bold typography — "See Your Project Before It's Built" — readable
- Background image behind text (architectural render) — adds context
- "Start My Estimate" CTA button — clear action
- Bottom section with feature badges (Real-time Logic, VR Ready, Precise) — adds credibility
- Bottom nav bar (Estimate / Portfolio / Contact) — useful navigation
- Clean mobile layout, good spacing

**What needs to change (per agent system):**

| Element | Current (Stitch) | Problem | New version |
|---|---|---|---|
| Headline | "See Your Project Before It's Built" | Generic. Every render company says this. Fails anti-cliché test. | See below |
| Subtext | "Get an instant estimate for your visualization, VR experience, or design project" | Product-first, jargon-heavy. Fails decision certainty test. | See below |
| Feature badges | "Real-time Logic" / "VR Ready" / "Precise" | Technical features, not client outcomes. Who cares about "algorithmic pricing"? | See below |
| Bottom text | "Photorealistic renderings that capture every material nuance and lighting detail" | Classic cliché. Fails anti-cliché blacklist. | See below |
| "IMMERSIVE VR" label | "Step inside your blueprint with 1:1 scale virtual reality experiences" | Marketing speak. "1:1 scale virtual reality experiences" = jargon | See below |
| CTA | "Start My Estimate" | Not bad, but could be stronger | See below |

**Recommended Hero — Run through all 4 agents:**

```
SMALL LABEL:
RENDIMENSION EXPRESS

HEADLINE:
It's Not Seeing It.
It's Knowing It's Right.

SUBTEXT:
Get a clear estimate for your project in two minutes.
No jargon, no callbacks, no guessing.

CTA BUTTON:
Build My Estimate →

SECONDARY LINK:
View Our Work

BOTTOM BADGES (replace feature badges):
✓ 1,000+ projects delivered
✓ Results in 7–10 days
✓ Your deposit counts toward the project
```

**Why this works:**
- Slogan IS the headline. It's strong enough to carry the page.
- Subtext is 8th-grade level, practical, removes anxiety.
- Badges sell outcomes and trust, not technical features.
- No "photorealistic" or "immersive" anywhere.

**IMPORTANT DECISION: This is where the dual-path split should happen.**

Instead of these 6 cards, this screen should FIRST ask who the client is,
then adapt everything after.

- Instantly segments homeowner vs. professional

- No jargon, 8th-grade level, calm tone

## COMPLETE FLOW BLUEPRINT

### Flow A: Homeowner / Personal Project

```
Screen 1: HERO
  Slogan + CTA + trust badges

Screen 2: WHO ARE YOU?
  → "I'm planning a personal project"

Screen 3: WHAT ARE YOU WORKING ON?
  Kitchen renovation / Home remodel / New home /
  Interior redesign / Outdoor-landscape / Other

Screen 4: WHAT DO YOU WANT TO BE SURE ABOUT?
  - See how everything will look before building
  - Compare materials and layouts
  - Show the design to family or partners
  - Get approval images (HOA, permits)
  - I just need a quick price

Screen 5: RECOMMENDED PACKAGE
  System recommends based on answers.
  Shows package + price range.
  "Customize" expands to full configurator.

Screen 6: YOUR INFO
  Name, email, phone, project name, description

Screen 7: YOUR ESTIMATE
  Itemized total + tiered CTA + trust + slogan
```

**Total: 7 screens, but screens 2-4 are single-tap cards (fast).**
**Effective time: ~2 minutes.**

---

### Flow B: Professional / Client Project

```
Screen 1: HERO
  Slogan + CTA + trust badges

Screen 2: WHO ARE YOU?
  → "I'm working on a client project"
  (or "Skip to services" link)

Screen 3: PROJECT TYPE
  Residential Single / Multi-Family / Commercial /
  Hospitality / Mixed-Use / Interior / Outdoor

Screen 4: BUILD YOUR PACKAGE (full configurator)
  All services with checkboxes, sliders, running total

Screen 5: YOUR INFO
  Name, email, phone, company, description

Screen 6: YOUR ESTIMATE
  Itemized total + tiered CTA + trust + slogan
```

**Total: 6 screens. Professional path is 1 screen shorter.**
**Effective time: ~90 seconds for someone who knows what they want.**
