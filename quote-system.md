## Core Positioning

- We do NOT sell renders. We sell certainty before construction decisions.
- We do NOT price based on number of renders. We price based on project impact, client level, and business outcome.
- "We don't start with renders. We define the concept... then we visualize it."

## Pricing Tiers (4 levels)

| Tier | Descripción | Option A (Limited) | Option B (Recommended) | Option C (Full Vision) |
|---|---|---|---|---|
| 1 Small | Basic visualization projects | $5K - $8K | $9K - $12K | $13K - $15K |
| 2 Mid | Concept + visualization | $12K - $16K | $18K - $25K | $28K - $35K |
| 3 High Value | Full strategy + premium viz | $30K - $40K | $45K - $60K | $70K - $80K+ |
| 4 Strategic | Investor-grade, full scope | $70K - $85K | $95K - $120K | $140K - $150K+ |

## Pricing Rules

- NEVER go below $5K for any project
- If strategy/concept is included → minimum Tier 2 ($12K+)
- If project involves investors, sales, or positioning → increase pricing within tier
- If client has no clear concept → bump up 1 tier (consulting work = more value)
- **Option B is ALWAYS the target closing price** (psychological anchor)
- Option A exists to make B look reasonable
- Option C exists to stretch the client and increase perceived value of B
- Use psychological pricing: $16,500 feels closer to $15K than $20K; $9,500 feels like single digits

## Deliverables (always generated)

### 1. Proposal PDF (the closer)
Structure (6 sections, this exact order):
1. Cover — Project name, city, Rendimension branding
2. The Problem — "Most [project type] projects fail because..." Attack the pain point. NO mention of renders.
3. Our Approach — "We define the concept first. Then we visualize it." Three phases.
4. Scope Breakdown — What each option includes
5. Pricing — Three options. B gets star and "Recommended" tag. Gold highlight on B.
6. Closing — "This is not about creating images. It's about building a project that works before you build it."

### 2. Market Insights PDF (the price justifier)
- Market Context — Real data about the city/sector
- The Opportunity — What competitors are missing
- Common Mistakes — Failed projects, bad planning
- Strategic Direction — What Rendimension would do differently

### 3. Interactive HTML (the wow factor)
- Single-page scroll combining Proposal + Insights
- Dark premium design: BG #0D0D0D, cards #1A1A1A, gold #C9A84C
- Fonts: Playfair Display (headers) + Inter (body)
- Fade-in animations, mobile responsive

## Sales Psychology Rules

- Talk about BUSINESS, not design
- Talk about RESULTS, not deliverables
- Position as STRATEGIC PARTNER, not rendering service
- Never justify price with hours worked
- The Insights PDF does the selling — the Proposal PDF does the closing
- Client should focus on the SOLUTION, not the PRICE
- Always address the client's "pain" first, solution second, price last

## Banned Phrases

NEVER use in any deliverable:
- "visualize your vision"
- "bring ideas to life"
- "stunning renderings / stunning visuals"
- "immersive experience(s)"
- "cutting edge" / "state of the art" / "world-class"
