## TESTING PLAN

### Variable Being Tested Per Format

| Format | Variant A Tests | Variant B Tests | Variant C Tests |
|---|---|---|---|
| Format 1 (Doc / GM) | Pain hook intro | Stat hook intro | Question hook intro |
| Format 2 (Doc / DP) | Pain hook intro | Stat hook intro | FOMO hook intro |
| Format 3 (Single / SM) | Time pain angle | Competence pain angle | New hire ramp angle |
| Format 4 (InMail / DP) | Closing rate ROI angle | New hire ramp angle | — |

All other variables (headline structure, document title, CTA button) held constant within each format to isolate the hook test.

### Kill / Scale Thresholds (LinkedIn)
- **Kill:** CTR < 0.2% after 5,000 impressions OR CPL > $400 after learning period
- **Scale:** CTR > 0.5% for 7+ consecutive days AND CPL < $250 — scale by max 20% budget increase
- **Learning period:** 7 days minimum. No changes days 1-3.

## OBJECTION PRE-HANDLING NOTES (for ad review)

These objections will surface in lead follow-up. The copy above is designed to pre-handle them before the prospect ever speaks to sales:

| Objection | How This Copy Pre-Handles It |
|---|---|
| "We already do training" | Stat hook (275% more confident) draws contrast between passive video and deliberate practice |
| "VR is a gimmick" | PwC attribution — not Reflex's claim — gives external credibility before skepticism forms |
| "Too expensive" | ROI math is shown before price is ever mentioned. The 30-day no-contract pilot removes commitment risk |
| "My reps are fine" | Question hook ("what happens when your rep chokes on a $60K buyer") creates doubt without accusation |
