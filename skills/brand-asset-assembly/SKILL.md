# Brand Asset Assembly

## Rendimension
- **Style**: Premium, sophisticated, architectural
- **Colors**: Clean whites, architectural grays, warm gold accent, dark charcoal backgrounds
- **Typography**: Modern sans-serif headlines, clean body
- **Imagery**: Photorealistic 3D renders as hero. Never low-res. Never stock photos.
- **Feel**: "This is what luxury looks like before it's built"

## Reflex
- **Style**: Professional, modern tech, results-driven
- **Colors**: Professional blue, clean white, growth green accent
- **Typography**: Bold sans-serif headlines, professional body
- **Imagery**: Dealership environments, VR headsets, data dashboards. No cartoons.
- **Feel**: "This is how top dealerships train"

## Asset Library Structure
```
campaign-assets/
├── rendimension/brand/ + meta/{images,videos,carousels}/
└── reflex/brand/ + linkedin/{images,videos,documents}/
```

## Consistency Rules
1. Same color palette per brand across all ads
2. Consistent logo placement
3. Consistent typography hierarchy
4. Don't mix photorealistic with illustrated
5. Consistent tone of voice across copy
