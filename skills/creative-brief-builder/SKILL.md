# Creative Brief Builder

## Brief Template
```
CREATIVE BRIEF
Brief ID: {brand}_{campaign}_{format}_{YYYYMMDD}
Brand: | Campaign: | Platform: | Format:

OBJECTIVE: What this ad must achieve
AUDIENCE: Who, what they care about, top objection
KEY MESSAGE: Hook, supporting message, proof, CTA

VISUAL DIRECTION:
- Mood, color palette, hero element, layout, style

COPY PLACEMENT:
- Headline, body, CTA, logo positions

ASSET SPECS:
- Dimensions, format, duration, slides

VARIANTS: A, B, C descriptions
PRODUCTION TOOL: Canva/Stitch/UIUX Pro/21ST + reason
```

## Tool Routing
| Asset Type | Complexity | Tool |
|---|---|---|
| Simple static, text overlay | Low | Canva |
| Carousel | Low-Medium | Canva |
| Layout exploration | Medium | Google Stitch |
| Landing page visuals | Medium-High | UIUX Pro |
| Premium campaign graphics | High | 21ST |

## Example: Rendimension Meta Carousel
- Hook: "See your project before construction"
- Cards: Hero kitchen → different angle → before/after → living room → CTA
- Specs: 1080x1080/card, 5 cards, Canva
- Variants: warm lighting / cool modern / dramatic contrast

## Example: Reflex LinkedIn Document
- Hook: "5 Reasons Your Sales Training Isn't Working"
- Pages: Cover → 4 reasons → CTA
- Specs: 1080x1080/page, 6 pages PDF, 21ST

## Checklist
- [ ] Hook clear and specific
- [ ] Message matches audience pain
- [ ] CTA actionable
- [ ] Specs match platform
- [ ] Brand guidelines followed
- [ ] Variants meaningfully different
- [ ] Tool assigned
