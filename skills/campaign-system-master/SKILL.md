# Campaign System Master

## Full Campaign Workflow

### Phase 1: Research (Days 1-3)
1. **Market & Audience Research Agent** profiles target segments
2. Competitive analysis using competitive-ads-extractor skill
3. **Offer & Positioning Agent** defines value proposition

### Phase 2: Creative Strategy (Days 3-5)
4. **Platform Format Agent** determines format per campaign
5. **Creative Brief Agent** produces production-ready briefs

### Phase 3: Production (Days 5-8)
6. **Copywriting Agent** writes 3+ copy variants per ad
7. **Visual Production Agent** routes to Canva/Stitch/UIUX Pro/21ST

### Phase 4: Campaign Build (Days 8-10)
8. **Campaign Build Agent** structures campaigns with targeting and tracking
9. Launch checklist verification

### Phase 5: Post-Launch (Ongoing)
10. **Metrics Analyst Agent** reads performance daily
11. **Optimization Agent** makes adjustments weekly
12. **Reporting Agent** delivers weekly founder report
13. **Knowledge Librarian Agent** verifies all assets saved

## Decision Trees

### New Campaign Launch
Research → Offer → Format → Brief → Copy → Visuals → Build → Launch

### Weekly Optimization
Metrics → Analysis → Optimization Decisions → Report

### Creative Refresh
Format Review → New Briefs → New Copy → New Visuals → Swap in Campaign

### Scaling a Winner
Identify Winner → Duplicate Ad Set → Increase Budget 20% → Monitor 4 Days → Repeat

## Campaign Launch Readiness Checklist
- [ ] Personas documented
- [ ] Offer defined and validated
- [ ] 3+ ad format/variants produced
- [ ] Copy written with A/B variants (minimum 3 per concept)
- [ ] Visual assets in correct dimensions per platform
- [ ] UTM parameters configured
- [ ] Pixel/Insight Tag installed and verified
- [ ] Landing page live and mobile-tested
- [ ] Budget approved
- [ ] Campaign named per naming convention
- [ ] Lead form or conversion event configured

## Minimum Viable Campaign
- 1 campaign
- 2-3 ad sets (different audiences)
- 3-5 ads per ad set
- 3 copy variants × 2 visual variants
- 7-day learning period before any changes
