# Founder Preferences — Hugo Ramirez

## Communication
- Everything "digerido" (simplified)
- No jargon without explanation
- Plain business language
- Action items > data dumps
- Short, direct, actionable

## Reporting
- Weekly: 2-minute read max
- Traffic light system (green/yellow/red)
- Always: what happened, what's working, what to do
- Specific recommendations only

## Decision Making
- Batch approvals (don't ask one at a time)
- Present options with recommendations
- "If I were you, I would..." framing
- Trusts data over intuition

## Workflow
- Automation first (n8n)
- Pin successful nodes to freeze output
- Check for native n8n nodes before HTTP Request
- Leave items for approval, move to next

## Tools Available
- Canva, Google Stitch, UIUX Pro, 21ST
- WordPress for both brands
- n8n for automation

## Don'ts
- Long explanations before the point
- Asking to check things manually
- Vague recommendations
- Marketing jargon
- Multiple small approval requests
- Dashboards without interpretation
