# Creative Variant Production

## Variant Types
- **Copy variants**: same visual, different text (min 3)
- **Visual variants**: same text, different image (min 2)
- **Format variants**: same message, different container (2 formats recommended)
- **Audience variants**: same ad, different targeting (2-3 audiences)

## Minimums Per Campaign
- Meta: 3 copy × 2 visual = 6 ads, across 2-3 ad sets = 12-18 total
- LinkedIn: 3 copy × 1-2 visual = 3-6 ads, across 2-3 campaigns = 6-18 total

## Production Workflow
1. Start with best visual → 2. Write 3 copy variants → 3. Create 1-2 visual variants → 4. Adapt to formats/dimensions → 5. Name files → 6. Quality check → 7. Organize → 8. Register in index

## QC Checklist
- [ ] Matches brief | - [ ] Brand guidelines | - [ ] Mobile readable
- [ ] CTA clear | - [ ] Correct dimensions | - [ ] Under size limit
- [ ] Named correctly | - [ ] Visually distinct from other variants
