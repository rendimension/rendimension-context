# Meta Creative Matrix

## Hook Types That Work on Meta
1. **Visual Shock** — Dramatic render reveal, stunning architecture. Best for: awareness
2. **Curiosity Gap** — "This isn't a photo..." Best for: engagement
3. **Before/After** — Empty lot → finished rendering. Best for: lead gen, retargeting
4. **Social Proof** — Client testimonials, results. Best for: conversions
5. **Authority** — Process showcase, portfolio. Best for: consideration

## Format x Objective Matrix
| | Awareness | Engagement | Lead Gen | Conversions |
|---|---|---|---|---|
| Reel | Visual shock | Process reveal | CTA overlay | Testimonial |
| Carousel | Portfolio | Before/after | Multi-angle | Case study |
| Single Image | Hero render | Comparison | Strong CTA | Social proof |
| Video | Walkthrough | Making-of | Demo + form | Client story |

## Placement Strategy
- **Instagram Feed**: 1:1 or 4:5. Visual-first. Highest quality for visual products.
- **Facebook Feed**: 4:5 or 1:1. Most reach.
- **Stories/Reels**: 9:16. 15-30s. Hook in first 3 seconds. Native feel.
- **Facebook Marketplace**: 1:1. Good for retargeting. Transactional intent.

## Rendimension Best Practices
1. Lead with strongest rendering — always best visual first
2. Video: "wow shot" in first 2 seconds
3. Carousel: first card = hook, last card = CTA
4. Minimal text on images — let the render speak
5. Premium brand needs premium visuals — never use low-res
