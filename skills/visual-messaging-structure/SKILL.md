# Visual Messaging Structure

## 3-Second Rule
1. WHAT the ad is about (hero visual)
2. WHY it matters (headline)
3. WHERE to act (CTA)

## Hierarchy: Hero Visual (60-70%) → Primary Message (15-20%) → Supporting Text (5-10%) → CTA (5%)

## Text Overlay Rules
- Meta: <20% of image area, max 2 lines, min 24pt, high contrast
- LinkedIn: Text can be more prominent, clean professional look

## Color Psychology
| Color | Use For |
|---|---|
| White/Clean | Premium, trust |
| Blue | Professional, B2B |
| Black | Luxury, sophistication |
| Green | Growth, ROI, success |
| Orange | CTAs, urgency |

## Rendimension: Clean whites, architectural grays, warm gold accent, dark charcoal backgrounds
## Reflex: Professional blue, clean white, growth green accent, high contrast

## Layout: Single Image
Hero image (70%) → Headline (1-2 lines) → CTA button → Logo (corner)

## Layout: Carousel Card
Visual (80%) → Slide text (concise) → Swipe indicator

## Layout: Document Page
Headline (bold) → Supporting visual/data → Body (2-3 lines) → Brand footer
