# Winner Pattern Library

## Winner Card Template
```
WINNING AD PATTERN
Date: | Brand: | Platform: | Campaign:
Ad Name: | Format: | Hook Type: | Offer:
Headline: | Primary Text: | CTA:
CTR: | CPC: | CPL: | Conv Rate: | Duration: | Spend: | Leads:
WHY IT WORKS: 1. 2. 3.
HOW TO REPLICATE: 1. 2. 3.
```

## Pattern Recognition
1. Collect all ads with CPL below target for 7+ days
2. Group by hook type, format, offer
3. Identify commonalities
4. Document the pattern (not just the ad)
5. Test pattern with new creative

## Quarterly Review
1. Top 3 winning patterns?
2. What stopped working?
3. What new patterns to test?
4. Where to increase investment?
