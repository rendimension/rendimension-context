# Meta Campaign Builder

## Structure: Campaign → Ad Set → Ad

## Objectives: Lead Generation (recommended) | Traffic | Conversions | Awareness

## Budget: Start CBO $30-50/day testing → $50-100 optimizing → $100-300 scaling

## Rendimension Targeting
**Interests**: Architecture, Interior design, Real estate development, Construction, Luxury homes, Houzz, AutoCAD, SketchUp, 3D rendering
**Location**: Texas, Florida, California (primary)
**Age**: 28-65 | **Audience size**: 100K-2M ideal

## Custom Audiences: Website visitors, email list, video viewers 75%+
## Lookalikes: 1% of customers, leads, or visitors

## Placements: Instagram Feed (best for visual) → Facebook Feed → Stories → Reels

## Pixel Events: PageView, Lead, ViewContent, BookConsultation

## Launch Checklist
- [ ] Pixel installed and verified
- [ ] Conversion events configured
- [ ] Landing page live + mobile tested
- [ ] UTMs on all URLs
- [ ] Budget approved
- [ ] Audience 100K-2M
- [ ] Creative uploaded + previewed
- [ ] Copy proofread
- [ ] CTA correct
- [ ] Mobile preview checked

## Naming: `rendimension_meta_{objective}_{audience}_{YYYYMMDD}`
