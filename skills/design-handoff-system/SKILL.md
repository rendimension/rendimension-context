# Design Handoff System

## Tool-Specific Instructions

### Canva: Template, dimensions, text, brand colors, image, variants, export format
### Google Stitch: Elements to arrange, layout concept, hierarchy, color palette, mood references
### UIUX Pro: Page context, user flow, design system, responsive requirements, accessibility
### 21ST: Full brief, brand guidelines, quality expectations, references, exact specs

## Asset Delivery Checklist
- [ ] Correct dimensions | - [ ] Brand colors accurate
- [ ] Text readable mobile | - [ ] No spelling errors
- [ ] CTA visible | - [ ] Logo placed correctly
- [ ] File format correct | - [ ] File size within limits
- [ ] All variants produced | - [ ] Named per convention
- [ ] Saved to campaign-assets/

## Feedback Loop
1. Review against brief → 2. Specific feedback → 3. Max 2 revision rounds → 4. Approve → 5. Upload
